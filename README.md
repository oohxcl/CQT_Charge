# 常青藤充电桩订阅 · 个人使用改进版

基于 [PairZhu/CQT_Charge](https://github.com/PairZhu/CQT_Charge) 的 QQ 机器人，保留原项目的配置和指令方式，增加以下改进：

- **修复剩余时间显示**：`charge ps` 使用与订阅创建时间一致的时间基准，正确显示剩余分钟数。
- **满位继续等待**：空闲数量降为 0 时提示一次并继续监测，再次达到阈值时重新提醒；直到订阅到期或手动取消才结束。
- **推送显示空闲位置**：空位提醒及空闲数量变化提醒附带“几号充电桩、几号插座”。`charge list` 仍只显示站点和空闲数量。

## 快速开始

需要 Python 3.11 或更新版本、uv，以及已登录并开启 OneBot v11 正向 WebSocket 服务的 QQ 机器人（例如 NapCat）。

```bash
git clone https://github.com/oohxcl/CQT_Charge.git
cd CQT_Charge
uv sync
```

在项目目录创建 `.env`，填写自己的信息：

```dotenv
CQT_HOST=https://m.sgdq123.com:8601
OPEN_ID=填写自己的OpenID
PHONENUMBER=填写自己的手机号
LONGITUDE=填写站点附近的经度
LATITUDE=填写站点附近的纬度
QQ_TOKEN=填写OneBot服务令牌
ROBOT_WS_URL=ws://127.0.0.1:填写OneBot服务端口
MASTER_QQ=填写管理员QQ号
WORK_GROUP=填写机器人所在QQ群号
```

OpenID 来自本人常青藤小程序登录请求；管理页面地址与 OneBot WebSocket 服务地址不同，请使用实际服务配置。`.env` 和 `user_config.json` 不应提交到公开仓库。本仓库不包含账号、令牌或个人订阅数据。

```bash
uv run main.py
```

使用与机器人不同的 QQ 账号，在配置的群内发送纯文本指令，无需单独 @ 机器人：

| 指令 | 用途 |
|---|---|
| `charge help` | 查看完整帮助 |
| `charge list` | 查看附近可用站点及空闲数量 |
| `charge sub 天大卫津路24教院内 60 1` | 订阅指定站点 60 分钟，阈值为 1 |
| `charge ps` | 查看自己的订阅及剩余时间 |
| `charge stop 天大卫津路24教院内` | 取消该站点订阅 |

请将示例站名替换成 `charge list` 返回的名称。多个站点可分别订阅。启动订阅时已有足够空位会提醒；满位后无需重新订阅。原项目的偏好设置和 @ 机器人快捷操作保持原有行为，详见 `charge help`。

## 位置显示与请求开销

位置只在需要推送空位消息时额外查询，同站多用户共享短期缓存；空闲数量不变时不持续查询详情。位置示例：

```text
当前空闲充电位数量：2
空闲位置（详情查询时）：
  1号充电桩：2号、7号插座
```

汇总数量和设备详情来自两次请求，可能不一致；程序会标注差异。详情查询失败时仍推送汇总数量。位置仅代表详情查询时的状态，不保证到达时仍空闲。

本版本更适合个人或少量站点使用。按当前 15 秒轮询、离线模拟一小时：单站空位不变时请求由 240 次增至 241 次；空闲数每次轮询在 1、2 之间变化时增至 480 次；3 个站点均如此变化时请求需求为 960 次。实际还有请求间隔限制，负载高时会排队或超时。空闲数不变但具体插座互换时，当前不会额外提醒。

电脑睡眠或关机时程序无法持续运行；微信最小化不影响通过接口查询，QQ 机器人服务及本程序需保持运行。

## 离线测试

无需登录 QQ 或访问充电接口：

```bash
python -m unittest discover -s tests -v
```

覆盖剩余时间、满位继续等待、到期及手动取消、位置格式、缓存共享、详情失败和列表展示。
